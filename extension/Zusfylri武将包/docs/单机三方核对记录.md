### 2. 嬴政 / 始皇帝 / `zus_yingzheng`

当前状态：
- 已修复，待单机回归验证

图片来源：
- `image/character/zus_yingzheng.png`

代码来源：
- `module/yingzheng.js`

结论：
- `夷灭`、`皇道` 的大意基本与图片一致。
- `销镝` 的实际触发时机和效果细节与图片不一致。

发现的问题：
- 图片写的是“游戏开始前”，代码触发时机是 `global: "gameDrawAfter"`，不等于开始前。

判定：
- 技能实际效果与图片不一致
- 技能描述存在歧义，且当前实现更接近“各移出一张牌”

修复记录：
- 已将 `销镝` 触发时机前移到开局前。
- 已将 `销镝` 改为从牌堆中选择并移出 `一种武器` 与 `一种防具`，不再只移出单张牌。

### 3. 吴京 / 战狼 / `zus_wujing`

当前状态：
- 已修复，待单机回归验证

- `image/character/zus_wujing.png`

- `module/wujing.js`

修复记录：
- 已将 `漂移` 的后半段改为只能把 `1个“狼”` 转移给本次被【闪】抵消的那张【杀】的目标。
