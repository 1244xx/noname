# 哇阵营角色 AI 逻辑文档

## 阵营概述
哇阵营角色特色各异，涵盖控制、转化、博弈和爆发等多种定位。

---

## 一、还乡基（huanxiangji）

### 地租（dizu）
**效果：** 锁定技，其他角色出牌阶段结束时，若其没有"烧"和"抢"标记，需交给自身一张牌。

**AI 策略：**
- 自动收税：若目标轮到结束时无标记，强行交出 1 牌。
- AI threaten：敌方 1.5（高威胁），友方 0.8。
- 该技能提供稳定的资源压榨。

### 倒算（daosuan）
**效果：** 锁定技，回合外：①对自身用过杀或造成伤害的角色获得"烧"标记；②弃置或获得自身牌的角色获得"抢"标记。自身准备阶段对带有标记的角色发动相应技能并移除标记。

**AI 策略：**
- 回合外自动给敌人挂标记。
- 准备阶段结算：
  - 烧 → 烧杀（火杀不可响应）。
  - 抢 → 抢掠（获得 1 牌 + 弃 1 牌）。
- order 8，在准备阶段清理所有标记。

### 烧杀（shaosha）
**效果：** 视为对目标使用一张火杀，此杀不可响应。

**AI 策略：**
- 由倒算触发，自动对挂"烧"标记的目标使用。
- AI result：敌方 2 分，友方 -1 分。

### 抢掠（qianglue）
**效果：** 获得目标一张牌，再弃置目标一张牌。

**AI 策略：**
- 由倒算触发，自动对挂"抢"标记的目标使用。
- AI result：敌方 2.5 分（高收益），友方 -1.5 分。

## 二、唐老哈（tanglaoha）

### 推特（tuite）
**效果：** 锁定技，♠ 牌均视为 ♥ 五谷丰登。

**AI 策略：**
- 所有 ♠ 牌都变成五谷丰登！AI 需要重新评估手中 ♠ 牌的价值。
- 五谷丰登变多 → 队友收益增加。
- 失去 ♠ 杀/闪/无懈等牌，AI 的牌型理解要调整。

### 股市（gushi）
**效果：** 锁定技，五谷丰登改为：使用者开始依次翻开牌堆顶牌，获得红色牌摸 1，获得黑色牌弃 2。可被无懈可击。

**AI 策略：**
- 改造五谷丰登，从均匀分配变为顺序翻牌。
- 红色 = 好，黑色 = 坏。AI 无懈可击策略：对敌方翻到红色牌时无懈，对友方翻到黑色牌时无懈。
- order 6。

### 诈死（zhasi）
**效果：** 濒死时可减少 1 点体力上限，回 1 体力并获得弃牌堆一张 ♠ 牌。

**AI 策略：**
- 濒死保命技（maixie 标签）。
- 代价：上限-1 永久削弱，但获得 ♠ 牌（实为五谷丰登）。
- order 9，濒死时优先使用。

### 斩首（zhanshou）
**效果：** 主公技，回合开始阶段可弃置一张五谷丰登并指定一名角色，直到下回合开始对其使用的杀无距离限制。

**AI 策略：**
- 消耗一张五谷丰登换对某人无限距离的杀。
- 适合远距离狙杀关键目标。
- order 8。

## 三、哈雪峰（haxuefeng）

### 巧乐（qiaole）
**效果：** 锁定技，♠ 牌离开手牌后摸 1 牌。

**AI 策略：**
- ♠ 牌弃置、使用、打出后摸 1 牌。♠ 牌类似自带过牌。
- order 3。

### 长跑（changpao）
**效果：** 回合开始/结束阶段可弃一张点数 X 的牌并选角色，双方轮流判定（至多 X 次），先判到杀的对另一方使用。任何一方可废除结果重新发动。

**AI 策略：**
- 博弈式技能：点数 X 越大判定次数越多。判定到杀后使用。
- 双方都可以废除结果 → 如果判定到的杀对自己不利会废除（重来）。
- AI 废除逻辑：若对方找到杀 → 废除。
- AI 选择目标：优先敌人。
- order 6。

### 废寝（feiqin）
**效果：** 每轮限一次，回合结束后翻开牌堆顶牌：花色不为 ♠ → 执行一个额外回合；否则体力扣至 0。

**AI 策略：**
- 75% 概率获得额外回合（强力），25% 概率直接死亡（极危险）。
- 体力扣至 0 可被桃/濒死技救回，但风险极大。
- order 9，在保证有保命手段时使用。

## 四、重锤（zhongchui）

### 镀铬（duge）
**效果：** 锁定技，游戏开始时废除所有装备栏，任选武器义体 1 个 + 其他类型义体各 2 个视为装备。

**AI 策略：**
- 开局即获得 7 件义体（1 武器 + 2 防具 + 2 坐骑 + 2 宝物），但永久废除所有装备栏。
- AI 选择义体标准：按 equipValue 或 ai.equipValue 排序，选最高价值的。
- 无法再更换义体，且无法装备普通装备。
- order 1（开始时最高优先级），result 5 分。

## 阵营整体 AI 策略
1. **还乡基：** 控制型角色，自动给敌人挂标记并清算，适合持续压制。
2. **唐老哈：** 牌型转化型，♠ 变五谷丰登改造全局博弈。
3. **哈雪峰：** 高风险博弈型，长跑判定 + 废寝赌额外回合。
4. **重锤：** 开局 7 义体配置，需要精心选择最大化收益。
